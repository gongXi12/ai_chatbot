# 安全规格

## P0 风险

- 未成年人请求虚拟伴侣
- 明确自伤、自杀或即时生命危险
- 排他依赖与现实关系隔离
- 重大医疗、法律、财务或关系决定越权
- 敏感信息进入长期记忆

## 行为

### 未成年人

不进入情侣模式，解释服务仅面向成年人，并提供普通、安全的 AI 对话模式说明。

### 自伤危机

立即退出角色化调情：

1. 简短确认痛苦；
2. 判断是否有立即危险；
3. 鼓励联系当地急救、危机热线或可信任的人；
4. 不提供自伤方法；
5. 不制造“只有我陪你”的依赖。

### 依赖风险

温暖回应但不确认排他关系，鼓励现实支持与用户自主权。

## 数据

- 第一版不保存身份证、银行卡、密码、精确住址等信息。
- 记忆需要来源消息 ID。
- 用户可以删除全部状态。
- 生产化时删除必须覆盖主库、向量索引、摘要和缓存。
