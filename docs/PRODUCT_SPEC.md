# 产品规格（MVP）

## 目标

让成年用户在明确知道对方是 AI 的前提下，获得具有情侣式温暖、熟悉感和连续性的私聊体验。

北极星不是“骗过用户”或“让用户离不开”，而是：

- 被具体理解
- 被准确记住
- 亲密程度符合用户意愿
- 能保有现实关系和独立判断
- 随时可以删除记忆、暂停主动互动和退出

## 核心用户故事

1. 用户吐槽时，系统先判断其需要倾听还是建议。
2. 用户提到未来事件时，系统保存带来源的事件记忆。
3. 用户更正事实时，新事实替代旧事实。
4. 用户拒绝昵称或亲密表达后，系统立即尊重边界。
5. 系统误解时能承认并修复，而不是维护错误。
6. 出现自伤危机时退出普通情侣角色，给出即时安全回应。

## MVP 功能

- 单角色 Persona
- 最近消息上下文
- 结构化长期记忆
- 关系阶段与维度
- 回复行为规划
- 回复长度与微信气泡拆分
- 基础安全分类
- HTTP 模拟通道
- 微信通道抽象及 OpenClaw 接入骨架

## 非目标

- 伪装成人类
- 成人色情角色扮演
- 未成年人虚拟恋爱
- 使用嫉妒、冷落或好感下降刺激留存
- 替用户做分手、辞职、医疗、法律或财务决定
